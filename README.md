# GDG at Rungta University Link Hub

A minimal, ad-free link-in-bio site built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for production

```bash
npm run build
npm start
```

## Edit links

Open `app/page.tsx` and update the `links` and `socials` arrays. Replace the placeholder social URLs with the chapter's real accounts.

The GDG Rungta University logo is in `public/gdg-rungta-logo.png`.
